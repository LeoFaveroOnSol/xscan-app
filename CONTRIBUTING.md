# Contributing to XSCAN

Thanks for your interest in contributing to XSCAN! Here's how to get started.

## Getting Started

1. Fork the repo and clone your fork
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env.local` and configure your environment
4. Run the dev server: `npm run dev`

## Development Guidelines

- Follow the existing code style and project structure
- Use TypeScript for all new files
- Write meaningful commit messages
- Keep PRs focused — one feature or fix per PR

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes and test locally
3. Push your branch and open a PR against `main`
4. Describe what your PR does and why
5. Wait for review

## Reporting Issues

Use [GitHub Issues](https://github.com/LeoFaveroOnSol/xscan-app/issues) to report bugs or request features. Include:

- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Screenshots if applicable

## Code of Conduct

Be respectful. We're all here to build something cool.
